# Single-period Delivery Optimization

This project studies a single-period, two-level retail distribution problem
with multiple plants, multiple dealers, multiple SKUs, heterogeneous vehicle
types, and minimum shipment quantities.

## Implemented Methods

- `monolithic/`: direct integer-programming model solved with Gurobi.
- `column-generation/`: master problem and pricing subproblem implementation.
- `heuristic/`: fast two-stage heuristic for larger operational instances.

The repository includes a small sample instance under
`datasets/single-period/small/dataset_9`.

## Setup

```powershell
python -m venv .venv
& .\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install gurobipy pandas numpy matplotlib seaborn rich
```

## Running

The entry scripts are kept in the algorithm folders because the original
research code used local imports.

```powershell
cd monolithic
python OPTSingle.py

cd ..\heuristic
python main.py

cd ..\column-generation
python OPTCG.py
```

Before running, inspect the input/output paths in each entry script and the
configuration generated by `params_config.py`. Gurobi license configuration
is required for the exact and column-generation solvers.

## Research Output

The reported experiments compare the monolithic model, column generation,
and the two-stage heuristic on objective value and runtime. The full result
files are excluded from this repository, while the code and sample instance
are retained for reproducibility.
