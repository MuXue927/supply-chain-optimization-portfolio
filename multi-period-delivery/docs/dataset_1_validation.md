```text
datasets/multiple-periods/small/dataset_1
OutPut-ALNS/multiple-periods/small/dataset_1
```

The validation combines:

- result-file consistency checks;
- demand and inventory reconstruction;
- vehicle-capacity and minimum-load checks;
- cost decomposition checks;

valid Gurobi license. ILP-related checks are therefore limited to code review.

## Cost Decomposition

The current optimal solution generated by the corrected code has:

| Cost component | Value |
|---|---:|
| Fixed vehicle activation cost | 75.0 |
| Minimum-load penalties | 78.0 |
| Total actual objective | 153.0 |

The minimum-load penalty follows the thesis formula:

```text
penalty = alpha * vehicle_cost
```

for every used vehicle whose loaded volume is below its vehicle-type minimum.

In the current solution:

- 75 vehicles are used;
- 39 vehicles are below the minimum-load threshold;
- those underloaded vehicles pay a penalty rather than making the solution
  infeasible;
- the penalty is included in the final objective and in `opt_summary.csv`.

## Issues Found and Fixed

### Minimum-load penalty was omitted from the actual objective

The original `actual_objective()` used `param_pun_objective`, but the generated
configuration did not define that field. As a result, the objective contained
only fixed vehicle cost and ignored minimum-load penalties.

The implementation now:

- reads `alpha` from `model_config_alns.json`;
- defaults to the thesis formula when `pun_objective` is absent;
- includes the minimum-load penalty in the tracked and final objective.

### Final solution selection could override the best actual solution

The callback-maintained feasible state previously had unconditional priority
over the tracker's best actual-objective state. This could replace a better
actual solution with a worse one.

The final selection now compares both feasible candidates by actual objective
and uses vehicle count only as a tie-breaker.

### Final consolidation could increase the actual objective

Final consolidation was accepted whenever it remained feasible. It now rolls
back if consolidation increases the actual objective.

### Repair-operator count differed from the thesis

The thesis describes eight repair operators. The implementation was registering
an additional `infeasible_repair` wrapper as a search operator.

That wrapper remains available as a feasibility fallback in callbacks and
initial-solution repair, but it is no longer registered as one of the eight
ALNS repair operators.

## Remaining Notes

- The 39 underloaded vehicles are allowed because the mathematical model uses a
  penalty rather than a hard feasibility constraint.
- No Gurobi or ILP result comparison is included in this report.
- The validation confirms internal consistency and objective alignment; it does
  not prove global optimality of the ALNS solution.
